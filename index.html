完整操作教學

從下載到開始傳送

1

下載並安裝

一般使用者下載安裝版，依畫面按「下一步」，並保留建立桌面捷徑。

2

登入 LINE 電腦版

先開啟 LINE 電腦版並完成登入，再開啟桌面的工作台。

3

取得通行碼

到官方 LINE 輸入「申請通行碼」或「申請授權碼」，取得七碼大寫英文與數字組合。

4

驗證並啟動

在啟動面板輸入七碼通行碼，按「驗證並啟動」。首次成功後會綁定目前電腦。

5

連接 LINE

進入工作台後先按「連接 LINE」，等待畫面顯示已連接，再設定任務。

6

設定對象

輸入好友或群組顯示名稱，一行一個，加入排程前再次核對。

7

準備內容

設定文字或圖片內容，先以自己的測試群組確認結果。

8

設定排程

確認傳送時間後加入排程。執行時 LINE 與工作台都必須保持開啟。

疑難排解

下載時被 Edge／Chrome 阻擋

確認目前網址是 dw5000tw-33.github.io/lineauto，且檔名與本頁一致，再選擇「保留」或「仍要保留」。不要關閉防毒軟體。

Windows 顯示未知發行者或已保護您的電腦

目前尚未加入付費數位簽章。確認來源後按「其他資訊」→「仍要執行」。

雙擊後沒有反應，或黑色視窗閃一下

請改用安裝版，並確認安裝完整。免安裝版必須先「全部解壓縮」，不能直接在 ZIP 裡執行，也不能拆散資料夾內的檔案。

通行碼無效、到期或找不到

通行碼為七碼大寫英文與數字。請重新複製貼上；若仍失敗，到官方 LINE 輸入「問題回報」並附上畫面截圖。

顯示通行碼已綁定其他電腦

第一次成功驗證時會綁定裝置。若已換電腦，請聯絡官方 LINE 協助確認，不要重複購買。

工作台無法連接 LINE

先確認 LINE 電腦版已登入且視窗已開啟，再重新按「連接 LINE」。仍無法連接時，關閉 LINE 與工作台後重新開啟。

搜尋不到好友或群組

請使用 LINE 上完整顯示名稱，一行一個。建議先在 LINE 搜尋欄確認該名稱確實找得到。

排程時間到了卻沒有執行

確認電腦保持開機、登入、未鎖定且未進入睡眠；LINE 與工作台都必須保持開啟。

桌面 Logo 還是舊圖示

先解除安裝舊版，再重新安裝最新版。若仍顯示舊圖示，可重新啟動 Windows 檔案總管或電腦以清除圖示快取。

如何解除安裝

Windows「設定」→「應用程式」→「已安裝的應用程式」→「33 Works LINE 自動化工作台」→「解除安裝」。解除安裝不會自動解除裝置綁定。

仍未解決？到官方 LINE 輸入「問題回報」，請附上版本、完整錯誤畫面及發生前的操作步驟。截圖前請遮蔽私人訊息與個人資料。
